# DevDesk 🚀

A full-stack developer productivity platform.

## Features
- Secure authentication (JWT + httpOnly cookies)
- Task management
- Notes & code snippets
- AI-powered code improvement
- Analytics dashboard
- Search, pagination & rate limiting

## Tech Stack
- Next.js (App Router)
- TypeScript
- MongoDB + Mongoose
- shadcn/ui
- Gemini API

## Architecture
- Server-side authentication
- Protected API routes
- Modular models & services

## Getting Started
1. Clone repo
2. Add .env.local
3. npm install
4. npm run dev
